## Best Practices to Apply

From **react-components** skill:

- Modular components, no large single-file outputs
- TypeScript interfaces for all component props with `Readonly`
- Separate data from presentation
- Minimal props, clear composition

From **vercel-react-best-practices**:

- Server-side data prefetching where needed (none for static page)
- Minimal serialization at RSC boundaries
- Use of `React.memo()` for expensive components (chart)
- Lazy state initialization for any interactive state

From **building-components**:

- Proper slot-based composition
- Accessibility: ARIA labels, semantic HTML
- Consistent naming and structure
- Reusable, composable APIs
